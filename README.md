# Vigie — Surveillance de certificats SSL/TLS et de noms de domaine

Micro-SaaS de surveillance d'expiration de certificats SSL/TLS et de noms de domaine, ciblé TPE/PME et agences/MSP françaises.

Stack visée : Make/Zapier (vérifications périodiques) + Airtable (stockage) + Softr (portail client) + Stripe (facturation).

## Contenu du dépôt

- [`landing/index.html`](landing/index.html) — page de validation (liste d'attente, pas de backend, capture par email).

## Statut

Phase de validation du marché (landing page + liste d'attente) avant construction du produit no-code.
